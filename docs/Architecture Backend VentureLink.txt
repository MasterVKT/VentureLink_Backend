Architecture Backend VentureLink
Ce document décrit l'architecture complète du backend de l'application VentureLink, développée avec Django et Django REST Framework. Il sert de référence principale pour l'équipe backend et définit l'organisation du code, les patterns utilisés, et les choix techniques.
1. Vue d'ensemble
1.1 Principes architecturaux
Le backend de VentureLink suit une architecture basée sur Django, avec une organisation en couches permettant une séparation claire des responsabilités:
•	Modèles: Représentation des données et de la logique métier
•	Vues/API: Traitement des requêtes et génération des réponses
•	Services: Encapsulation des opérations complexes
•	Repositories: Abstraction de l'accès aux données (optionnel)
Cette architecture respecte les principes suivants:
•	DRY (Don't Repeat Yourself): Éviter la duplication de code
•	SOC (Separation of Concerns): Séparer clairement les responsabilités
•	KISS (Keep It Simple, Stupid): Privilégier les solutions simples
•	YAGNI (You Aren't Gonna Need It): N'implémenter que ce qui est nécessaire
•	API-first: Conception orientée API pour faciliter l'intégration frontend
1.2 Stack technologique
•	Framework: Django 4.2+
•	API: Django REST Framework
•	Base de données: PostgreSQL
•	Cache: Redis
•	Authentification: JWT avec Firebase Auth
•	Stockage de fichiers: Système de fichiers + CDN
•	Monitoring: Sentry, Prometheus
•	Documentation API: Swagger/OpenAPI
•	Tests: pytest
•	CI/CD: GitHub Actions
•	Déploiement: Docker, Kubernetes

from django.db import models
from django.utils.translation import gettext_lazy as _
from django.contrib.auth import get_user_model
from apps.core.models import TimeStampedModel, UUIDModel

User = get_user_model()

class Project(TimeStampedModel, UUIDModel):
    """
    Modèle représentant un projet.
    """
    STAGE_CHOICES = (
        ('IDEA', _('Idea')),
        ('PROTOTYPE', _('Prototype')),
        ('DEVELOPMENT', _('Development')),
        ('GROWTH', _('Growth')),
    )

    STATUS_CHOICES = (
        ('ACTIVE', _('Active')),
        ('INACTIVE', _('Inactive')),
        ('FUNDED', _('Funded')),
        ('ARCHIVED', _('Archived')),
    )

    creator = models.ForeignKey(
        User,
        on_delete=models.CASCADE,
        related_name='created_projects',
        verbose_name=_('Creator')
    )
    title = models.CharField(_('Title'), max_length=100)
    short_description = models.TextField(_('Short description'), max_length=280)
    full_description = models.TextField(_('Full description'), max_length=5000)
    category = models.ForeignKey(
        'ProjectCategory',
        on_delete=models.SET_NULL,
        null=True,
        blank=True,
        related_name='projects',
        verbose_name=_('Category')
    )
    stage = models.CharField(
        _('Stage'),
        max_length=20,
        choices=STAGE_CHOICES,
        default='IDEA'
    )
    funding_min = models.DecimalField(
        _('Minimum funding'),
        max_digits=14,
        decimal_places=2,
        null=True,
        blank=True
    )
    funding_max = models.DecimalField(
        _('Maximum funding'),
        max_digits=14,
        decimal_places=2,
        null=True,
        blank=True
    )
    funding_currency = models.CharField(
        _('Currency'),
        max_length=3,
        default='EUR'
    )
    location_country = models.CharField(
        _('Country'),
        max_length=100,
        null=True,
        blank=True
    )
    location_city = models.CharField(
        _('City'),
        max_length=100,
        null=True,
        blank=True
    )
    tags = models.ManyToManyField(
        'ProjectTag',
        through='ProjectTagRelation',
        related_name='projects',
        verbose_name=_('Tags')
    )
    is_premium = models.BooleanField(_('Premium'), default=False)
    is_featured = models.BooleanField(_('Featured'), default=False)
    is_draft = models.BooleanField(_('Draft'), default=False)
    status = models.CharField(
        _('Status'),
        max_length=20,
        choices=STATUS_CHOICES,
        default='ACTIVE'
    )
    views_count = models.PositiveIntegerField(_('Views count'), default=0)
    interests_count = models.PositiveIntegerField(_('Interests count'), default=0)
    favorites_count = models.PositiveIntegerField(_('Favorites count'), default=0)
    published_at = models.DateTimeField(_('Published at'), null=True, blank=True)
    business_plan = models.FileField(
        _('Business plan'),
        upload_to='projects/business_plans/',
        null=True,
        blank=True
    )
    video_url = models.URLField(_('Video URL'), null=True, blank=True)

    class Meta:
        verbose_name = _('Project')
        verbose_name_plural = _('Projects')
        ordering = ['-created_at']
        indexes = [
            models.Index(fields=['creator', '-created_at']),
            models.Index(fields=['category', '-created_at']),
            models.Index(fields=['status', '-created_at']),
            models.Index(fields=['stage', '-created_at']),
            models.Index(fields=['location_country', '-created_at']),
            models.Index(fields=['-views_count']),
            models.Index(fields=['-interests_count']),
        ]

    def __str__(self):
        return self.title

    def increment_views(self):
        """Incrémente le compteur de vues"""
        self.views_count += 1
        self.save(update_fields=['views_count'])

    def increment_interests(self):
        """Incrémente le compteur d'intérêts"""
        self.interests_count += 1
        self.save(update_fields=['interests_count'])

    def increment_favorites(self):
        """Incrémente le compteur de favoris"""
        self.favorites_count += 1
        self.save(update_fields=['favorites_count'])

    def decrement_favorites(self):
        """Décrémente le compteur de favoris"""
        if self.favorites_count > 0:
            self.favorites_count -= 1
            self.save(update_fields=['favorites_count'])

    @property
    def primary_image(self):
        """Retourne l'image principale du projet"""
        return self.media.filter(is_primary=True).first()

    @property
    def all_media(self):
        """Retourne tous les médias du projet, triés par ordre"""
        return self.media.all().order_by('order')

Utilisation de ViewSets pour regrouper les opérations CRUD:
# apps/projects/views/project_views.py
from rest_framework import viewsets, mixins, status, filters
from rest_framework.decorators import action
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated
from django_filters.rest_framework import DjangoFilterBackend
from drf_spectacular.utils import extend_schema, OpenApiParameter

from apps.core.permissions import IsProjectOwnerOrReadOnly, IsPremiumUser
from apps.projects.models import Project, ProjectInterest, ProjectMedia
from apps.projects.serializers import (
    ProjectSerializer, ProjectDetailSerializer, ProjectCreateSerializer,
    ProjectUpdateSerializer, ProjectInterestSerializer, ProjectMediaSerializer
)
from apps.projects.filters import ProjectFilter
from apps.projects.services import ProjectService

class ProjectViewSet(viewsets.ModelViewSet):
    """
    API endpoint qui permet de gérer les projets.
    """
    filter_backends = [DjangoFilterBackend, filters.SearchFilter, filters.OrderingFilter]
    filterset_class = ProjectFilter
    search_fields = ['title', 'short_description', 'full_description']
    ordering_fields = ['created_at', 'views_count', 'interests_count', 'favorites_count']
    ordering = ['-created_at']

    def get_queryset(self):
        """
        Retourne les projets visibles, avec des filtres supplémentaires
        pour les utilisateurs authentifiés.
        """
        if self.request.user.is_authenticated:
            # Utilisateurs authentifiés peuvent voir leurs projets en brouillon
            if self.action == 'list':
                return Project.objects.filter(
                    models.Q(is_draft=False, status='ACTIVE') | 
                    models.Q(creator=self.request.user)
                )
            return Project.objects.all()
        # Utilisateurs anonymes ne voient que les projets publiés
        return Project.objects.filter(is_draft=False, status='ACTIVE')

    def get_serializer_class(self):
        """
        Utilise différents sérialiseurs selon l'action.
        """
        if self.action == 'create':
            return ProjectCreateSerializer
        if self.action == 'update' or self.action == 'partial_update':
            return ProjectUpdateSerializer
        if self.action == 'retrieve':
            return ProjectDetailSerializer
        return ProjectSerializer

    def get_permissions(self):
        """
        Définit les permissions selon l'action.
        """
        if self.action in ['create', 'update', 'partial_update', 'destroy', 'publish']:
            return [IsAuthenticated(), IsProjectOwnerOrReadOnly()]
        if self.action in ['upload_business_plan']:
            return [IsAuthenticated(), IsProjectOwnerOrReadOnly(), IsPremiumUser()]
        return super().get_permissions()
    
    def perform_create(self, serializer):
        """
        Définit le créateur lors de la création d'un projet.
        """
        serializer.save(creator=self.request.user)
    
    @extend_schema(
        summary="Publier un projet en brouillon",
        description="Passe un projet de l'état brouillon à publié",
        responses={200: ProjectDetailSerializer}
    )
    @action(detail=True, methods=['post'], url_path='publish')
    def publish(self, request, pk=None):
        """
        Publie un projet qui était en brouillon.
        """
        project = self.get_object()
        service = ProjectService()
        
        published_project = service.publish_project(project)
        
        serializer = ProjectDetailSerializer(
            published_project,
            context={'request': request}
        )
        return Response(serializer.data)
    
    @extend_schema(
        summary="Ajouter un média au projet",
        description="Télécharge un fichier média (image, document) pour le projet",
        responses={201: ProjectMediaSerializer}
    )
    @action(detail=True, methods=['post'], url_path='media')
    def upload_media(self, request, pk=None):
        """
        Télécharge un média pour un projet.
        """
        project = self.get_object()
        file = request.FILES.get('file')
        
        if not file:
            return Response(
                {'error': 'Aucun fichier fourni'}, 
                status=status.HTTP_400_BAD_REQUEST
            )
        
        service = ProjectService()
        media = service.add_project_media(
            project=project,
            file=file,
            title=request.data.get('title'),
            description=request.data.get('description'),
            is_primary=request.data.get('is_primary', False),
            order=request.data.get('order', 0)
        )
        
        serializer = ProjectMediaSerializer(media)
        return Response(serializer.data, status=status.HTTP_201_CREATED)
    
    @extend_schema(
        summary="Télécharger un business plan (Premium)",
        description="Télécharge un business plan PDF pour le projet (réservé aux utilisateurs Premium)",
        responses={200: ProjectDetailSerializer}
    )
    @action(detail=True, methods=['post'], url_path='business-plan')
    def upload_business_plan(self, request, pk=None):
        """
        Télécharge un business plan (PDF) pour un projet.
        Réservé aux utilisateurs Premium.
        """
        project = self.get_object()
        file = request.FILES.get('file')
        
        if not file:
            return Response(
                {'error': 'Aucun fichier fourni'}, 
                status=status.HTTP_400_BAD_REQUEST
            )
        
        service = ProjectService()
        updated_project = service.add_business_plan(project, file)
        
        serializer = ProjectDetailSerializer(
            updated_project,
            context={'request': request}
        )
        return Response(serializer.data)
    
    @extend_schema(
        summary="Exprimer un intérêt pour un projet",
        description="Marquer son intérêt pour un projet avec un message optionnel",
        responses={201: ProjectInterestSerializer}
    )
    @action(detail=True, methods=['post'], url_path='interest')
    def express_interest(self, request, pk=None):
        """
        Exprime un intérêt pour un projet.
        """
        project = self.get_object()
        
        # Vérifier si l'utilisateur a déjà exprimé son intérêt
        if ProjectInterest.objects.filter(
            project=project, 
            user=request.user,
            status__in=['PENDING', 'ACCEPTED']
        ).exists():
            return Response(
                {'error': 'Vous avez déjà exprimé votre intérêt pour ce projet'},
                status=status.HTTP_400_BAD_REQUEST
            )
        
        # Vérifier que l'utilisateur n'est pas le créateur du projet
        if project.creator == request.user:
            return Response(
                {'error': 'Vous ne pouvez pas exprimer un intérêt pour votre propre projet'},
                status=status.HTTP_400_BAD_REQUEST
            )
        
        serializer = ProjectInterestSerializer(data=request.data)
        if serializer.is_valid():
            interest = serializer.save(
                project=project,
                user=request.user,
                status='PENDING'
            )
            
            # Incrémenter le compteur d'intérêts
            project.increment_interests()
            
            # Créer une notification pour le créateur du projet
            from apps.notifications.services import NotificationService
            notification_service = NotificationService()
            notification_service.create_interest_notification(interest)
            
            return Response(serializer.data, status=status.HTTP_201_CREATED)
        
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
    
    @extend_schema(
        summary="Ajouter aux favoris",
        description="Ajouter un projet à ses favoris avec des notes optionnelles",
        responses={201: {'type': 'object', 'properties': {'id': {'type': 'string'}}}}
    )
    @action(detail=True, methods=['post'], url_path='favorite')
    def add_to_favorites(self, request, pk=None):
        """
        Ajoute un projet aux favoris de l'utilisateur.
        """
        project = self.get_object()
        
        service = ProjectService()
        favorite = service.add_to_favorites(
            project=project,
            user=request.user,
            notes=request.data.get('notes')
        )
        
        # Incrémenter le compteur de favoris
        project.increment_favorites()
        
        return Response({'id': str(favorite.id)}, status=status.HTTP_201_CREATED)
    
    @extend_schema(
        summary="Retirer des favoris",
        description="Retirer un projet de ses favoris",
        responses={204: None}
    )
    @action(detail=True, methods=['delete'], url_path='favorite')
    def remove_from_favorites(self, request, pk=None):
        """
        Retire un projet des favoris de l'utilisateur.
        """
        project = self.get_object()
        
        service = ProjectService()
        removed = service.remove_from_favorites(
            project=project,
            user=request.user
        )
        
        if removed:
            # Décrémenter le compteur de favoris
            project.decrement_favorites()
        
        return Response(status=status.HTTP_204_NO_CONTENT)
    
    @extend_schema(
        summary="Obtenir les statistiques du projet (Premium)",
        description="Obtenir des statistiques détaillées sur un projet (réservé aux utilisateurs Premium)",
        responses={200: {'type': 'object'}}
    )
    @action(detail=True, methods=['get'], url_path='analytics', permission_classes=[IsAuthenticated, IsProjectOwnerOrReadOnly, IsPremiumUser])
    def analytics(self, request, pk=None):
        """
        Obtient des statistiques détaillées sur un projet.
        Réservé aux utilisateurs Premium qui sont propriétaires du projet.
        """
        project = self.get_object()
        
        service = ProjectService()
        analytics_data = service.get_project_analytics(project)
        
        return Response(analytics_data)

    def retrieve(self, request, *args, **kwargs):
        """
        Surcharge pour enregistrer les vues de projet.
        """
        instance = self.get_object()
        
        # Enregistrer la vue si ce n'est pas le créateur du projet
        if request.user != instance.creator:
            service = ProjectService()
            service.record_project_view(
                project=instance,
                user=request.user if request.user.is_authenticated else None,
                ip_address=request.META.get('REMOTE_ADDR'),
                user_agent=request.META.get('HTTP_USER_AGENT'),
                referrer=request.META.get('HTTP_REFERER')
            )
        
        serializer = self.get_serializer(instance)
        return Response(serializer.data)
3. Architecture en couches
3.1 Modèles
Les modèles Django représentent les données et la logique métier de base. Pour faciliter la réutilisation, nous utilisons des modèles abstraits:
# apps/core/models.py
import uuid
from django.db import models
from django.utils.translation import gettext_lazy as _

class TimeStampedModel(models.Model):
    """
    Modèle abstrait avec horodatage de création et mise à jour.
    """
    created_at = models.DateTimeField(_('Created at'), auto_now_add=True)
    updated_at = models.DateTimeField(_('Updated at'), auto_now=True)

    class Meta:
        abstract = True

class UUIDModel(models.Model):
    """
    Modèle abstrait avec identifiant UUID.
    """
    id = models.UUIDField(
        _('ID'),
        primary_key=True,
        default=uuid.uuid4,
        editable=False
    )

    class Meta:
        abstract = True

class UserViewSet(mixins.RetrieveModelMixin,
                  mixins.UpdateModelMixin,
                  viewsets.GenericViewSet):
    """
    API endpoint pour gérer les utilisateurs.
    Ne permet que la récupération et la mise à jour, pas la création ou suppression.
    """
    serializer_class = UserSerializer
    permission_classes = [IsAuthenticated]

    def get_queryset(self):
        """
        Un utilisateur ne peut voir que son propre profil.
        """
        return User.objects.filter(id=self.request.user.id)

    @extend_schema(
        summary="Obtenir l'utilisateur courant",
        description="Retourne les informations de l'utilisateur authentifié",
        responses={200: UserSerializer}
    )
    @action(detail=False, methods=['get'], url_path='me')
    def me(self, request):
        """
        Retourne les informations de l'utilisateur authentifié.
        """
        serializer = self.get_serializer(request.user)
        return Response(serializer.data)

    @extend_schema(
        summary="Mettre à jour l'utilisateur courant",
        description="Met à jour les informations de l'utilisateur authentifié",
        responses={200: UserSerializer}
    )
    @action(detail=False, methods=['put', 'patch'], url_path='me')
    def update_me(self, request):
        """
        Met à jour les informations de l'utilisateur authentifié.
        """
        user = request.user
        partial = request.method == 'PATCH'
        serializer = self.get_serializer(user, data=request.data, partial=partial)
        
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data)
        
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)

    @extend_schema(
        summary="Changer le mot de passe",
        description="Permet à l'utilisateur de changer son mot de passe",
        responses={200: {'type': 'object', 'properties': {'message': {'type': 'string'}}}}
    )
    @action(detail=False, methods=['put'], url_path='password', serializer_class=UserPasswordChangeSerializer)
    def change_password(self, request):
        """
        Permet à l'utilisateur de changer son mot de passe.
        """
        serializer = UserPasswordChangeSerializer(data=request.data)
        
        if serializer.is_valid():
            user_service = UserService()
            
            if not user_service.check_password(request.user, serializer.validated_data['current_password']):
                return Response(
                    {'current_password': ['Mot de passe incorrect']},
                    status=status.HTTP_400_BAD_REQUEST
                )
            
            user_service.change_password(request.user, serializer.validated_data['new_password'])
            
            return Response({'message': 'Mot de passe modifié avec succès'})
        
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)

    def publish_project(self, project):
        """
        Publie un projet qui était en brouillon.
        """
        if not project.is_draft:
            return project
        
        # Vérifier que l'utilisateur n'a pas dépassé sa limite de projets actifs
        user = project.creator
        is_premium = hasattr(user, 'subscription') and user.subscription.is_active and user.subscription.plan in ['PREMIUM_MONTHLY', 'PREMIUM_YEARLY']
        
        active_projects_count = Project.objects.filter(

            status='ACTIVE'
        ).count()
        
        max_allowed = 5 if is_premium else 2
        if active_projects_count >= max_allowed:
            raise LimitReachedException(
                f"Vous avez atteint la limite de {max_allowed} projets actifs"
            )
        
        # Mettre à jour le projet
        project.is_draft = False
        project.published_at = timezone.now()
        project.save()

        """

        user = project.creator
        is_premium = hasattr(user, 'subscription') and user.subscription.is_active and user.subscription.plan in ['PREMIUM_MONTHLY', 'PREMIUM_YEARLY']

        max_allowed = 10 if is_premium else 3

            raise LimitReachedException(
                f"Vous avez atteint la limite de {max_allowed} médias par projet"
            )
        
        # Déterminer le type de fichier
        file_extension = os.path.splitext(file.name)[1].lower()
        if file_extension in ['.jpg', '.jpeg', '.png', '.gif']:
            file_type = 'IMAGE'

        elif file_extension in ['.mp4', '.mov', '.avi']:

        max_size = 10 * 1024 * 1024  # 10 MB
        if file.size > max_size:
            raise ValidationError("Fichier trop volumineux (maximum 10 MB)")
        
        # Si c'est l'image principale, désactiver les autres images principales
        if is_primary:
            project.media.filter(is_primary=True).update(is_primary=False)

        media = ProjectMedia.objects.create(
            project=project,
            file=file,
            file_type=file_type,
            title=title,
            description=description,
            is_primary=is_primary,

4.1 Intégration Firebase Authentication
L'authentification est gérée via Firebase Authentication, avec JWT pour les sessions:
# apps/users/authentication.py
import firebase_admin
from firebase_admin import auth
from rest_framework import authentication
from rest_framework.exceptions import AuthenticationFailed

from django.conf import settings
from django.contrib.auth import get_user_model
from django.utils.translation import gettext_lazy as _

from apps.users.models import UserProfile

User = get_user_model()

class FirebaseAuthentication(authentication.BaseAuthentication):
    """
    Authentification via Firebase Auth Token.
    """
    
    def authenticate(self, request):
        """
        Authentifie l'utilisateur via le token Firebase.
        """
        auth_header = request.META.get('HTTP_AUTHORIZATION')
        if not auth_header:
            return None
        
        id_token = auth_header.split(' ').pop()
        if not id_token:
            return None
        
        try:
            # Vérifier le token avec Firebase
            decoded_token = auth.verify_id_token(id_token)
            uid = decoded_token.get('uid')
            
            if not uid:
                raise AuthenticationFailed(_('Invalid token'))
            
            # Récupérer ou créer l'utilisateur
            user, created = self.get_or_create_user(decoded_token)
            
            return (user, id_token)
        except auth.InvalidIdTokenError:
            raise AuthenticationFailed(_('Invalid token'))
        except auth.ExpiredIdTokenError:
            raise AuthenticationFailed(_('Token expired'))
        except Exception as e:
            raise AuthenticationFailed(str(e))
    
    def get_or_create_user(self, decoded_token):
        """
        Récupère ou crée l'utilisateur correspondant au token Firebase.
        """
        uid = decoded_token.get('uid')
        email = decoded_token.get('email', '')
        
        # Chercher l'utilisateur par uid Firebase
        user = User.objects.filter(firebase_uid=uid).first()
        
        if user:
            return user, False
        
        # Chercher l'utilisateur par email
        user = User.objects.filter(email=email).first()
        
        if user:
            # Mettre à jour l'uid Firebase
            user.firebase_uid = uid
            user.save()
            return user, False
        
        # Créer un nouvel utilisateur
        name_parts = decoded_token.get('name', '').split(' ', 1)
        first_name = name_parts[0] if name_parts else ''
        last_name = name_parts[1] if len(name_parts) > 1 else ''
        
        user = User.objects.create(
            email=email,
            firebase_uid=uid,
            username=email,  # Utiliser l'email comme nom d'utilisateur
            first_name=first_name,
            last_name=last_name,
            is_active=True,
            is_verified=decoded_token.get('email_verified', False)
        )
        
        # Créer un profil vide
        UserProfile.objects.create(user=user)
        
        return user, True

from rest_framework import permissions

class IsProjectOwnerOrReadOnly(permissions.BasePermission):
    """
    Permission qui autorise uniquement le créateur du projet à le modifier.
    Les autres utilisateurs peuvent seulement lire.
    """
    
    def has_object_permission(self, request, view, obj):
        # Les méthodes de lecture sont toujours autorisées

            return True

class IsPremiumUser(permissions.BasePermission):
    """
    Permission qui autorise uniquement les utilisateurs premium.
    """
    
    def has_permission(self, request, view):
        user = request.user
        
        # Vérifier si l'utilisateur a un abonnement premium actif
        return (
            hasattr(user, 'subscription') and 
            user.subscription.is_active and 
            user.subscription.plan in ['PREMIUM_MONTHLY', 'PREMIUM_YEARLY']
        )

class IsConversationParticipant(permissions.BasePermission):
    """
    Permission qui autorise uniquement les participants d'une conversation.
    """
    
    def has_object_permission(self, request, view, obj):
        # Vérifier si l'utilisateur est un participant
        return obj.participants.filter(id=request.user.id).exists()
4.3 Middleware de limitation de débit
Protection contre les abus avec un middleware de rate limiting:
# apps/core/middleware.py
from django.conf import settings
from django.core.cache import cache
from django.utils.translation import gettext_lazy as _
from rest_framework.exceptions import Throttled
import time

class RateLimitMiddleware:
    """
    Middleware pour limiter le nombre de requêtes par utilisateur.
    """
    
    def __init__(self, get_response):
        self.get_response = get_response
    
    def __call__(self, request):
        # Ignorer le rate limiting pour certaines URL
        if self._should_skip_rate_limiting(request):
            return self.get_response(request)
        
        # Obtenir la clé de cache basée sur l'IP ou l'utilisateur
        key = self._get_cache_key(request)
        
        # Obtenir le taux limite en fonction de la méthode
        if request.method == 'GET':
            rate_limit = settings.RATE_LIMIT_GET
        else:
            rate_limit = settings.RATE_LIMIT_OTHER
        
        # Vérifier si l'utilisateur a dépassé la limite
        current_count = cache.get(key, 0)
        
        if current_count >= rate_limit:
            retry_after = self._get_retry_after()
            raise Throttled(
                detail=_('Request limit exceeded. Please try again later.'),
                wait=retry_after
            )
        
        # Incrémenter le compteur
        if current_count == 0:
            cache.set(key, 1, settings.RATE_LIMIT_WINDOW)
        else:
            cache.incr(key)
        
        return self.get_response(request)
    
    def _should_skip_rate_limiting(self, request):
        """
        Détermine si le rate limiting doit être ignoré pour cette requête.
        """
        # Ignorer les requêtes d'administration
        if request.path.startswith('/admin/'):
            return True
        
        # Ignorer les utilisateurs superutilisateurs
        if hasattr(request, 'user') and request.user.is_authenticated and request.user.is_superuser:
            return True
        
        return False
    
    def _get_cache_key(self, request):
        """
        Génère une clé de cache basée sur l'utilisateur ou l'IP.
        """
        if request.user.is_authenticated:
            identifier = f"user_{request.user.id}"
        else:
            identifier = f"ip_{self._get_client_ip(request)}"
        
        method_group = 'get' if request.method == 'GET' else 'other'
        
        return f"ratelimit:{identifier}:{method_group}"
    
    def _get_client_ip(self, request):
        """
        Récupère l'adresse IP du client.
        """
        x_forwarded_for = request.META.get('HTTP_X_FORWARDED_FOR')
        if x_forwarded_for:
            ip = x_forwarded_for.split(',')[0]
        else:
            ip = request.META.get('REMOTE_ADDR')
        return ip
    
    def _get_retry_after(self):
        """
        Calcule le temps d'attente avant la prochaine requête.
        """
        return settings.RATE_LIMIT_WINDOW

            return queryset.filter(
                models.Q(is_draft=False, status='ACTIVE') | 
                models.Q(creator=self.request.user)
            )
        
        # Précharger les favoris et intérêts de l'utilisateur courant

        queryset = queryset.prefetch_related(

            Prefetch('interests', queryset=ProjectInterest.objects.filter(user_id=user_id), to_attr='user_interests')
        )
        
        return queryset
    
    # Utilisateurs anonymes ne voient que les projets publiés
    return queryset.filter(is_draft=False, status='ACTIVE')

6.2 Service de notifications
Envoi de notifications via Firebase Cloud Messaging:
# apps/notifications/services/notification_service.py
from firebase_admin import messaging
import logging

from django.db import transaction
from django.utils import timezone

from apps.notifications.models import Notification, FCMNotification
from apps.projects.models import ProjectInterest
from apps.messaging.models import Message

logger = logging.getLogger(__name__)

class NotificationService:
    """
    Service pour la gestion des notifications.
    """
    
    @transaction.atomic
    def create_interest_notification(self, interest):
        """
        Crée une notification pour un nouvel intérêt sur un projet.
        """
        recipient = interest.project.creator
        sender = interest.user
        
        notification = Notification.objects.create(
            recipient=recipient,
            sender=sender,
            notification_type='NEW_INTEREST',
            title="Nouvel intérêt pour votre projet",
            message=f"{sender.first_name} {sender.last_name} est intéressé par votre projet {interest.project.title}",
            entity_type='PROJECT_INTEREST',
            entity_id=interest.id,
            action_url=f"/projects/{interest.project.id}/interests/{interest.id}"
        )
        
        # Envoyer la notification push
        self.send_push_notification(notification)
        
        return notification
    
    @transaction.atomic
    def create_message_notification(self, message):
        """
        Crée une notification pour un nouveau message.
        """
        sender = message.sender
        conversation = message.conversation
        
        # Envoyer une notification à tous les participants sauf l'expéditeur
        for participant in conversation.participants.exclude(id=sender.id):
            notification = Notification.objects.create(
                recipient=participant,
                sender=sender,
                notification_type='NEW_MESSAGE',
                title="Nouveau message",
                message=f"{sender.first_name} {sender.last_name} vous a envoyé un message",
                entity_type='MESSAGE',
                entity_id=message.id,
                action_url=f"/conversations/{conversation.id}"
            )
            
            # Envoyer la notification push
            self.send_push_notification(notification)
    
    def send_push_notification(self, notification):
        """
        Envoie une notification push via Firebase Cloud Messaging.
        """
        # Vérifier si le destinataire a un token FCM
        fcm_token = notification.recipient.fcm_token
        if not fcm_token:
            return
        
        # Créer le message FCM
        push_notification = messaging.Notification(
            title=notification.title,
            body=notification.message
        )
        
        # Données pour le traitement côté client
        data = {
            'type': notification.notification_type,
            'entity_id': str(notification.entity_id) if notification.entity_id else '',
            'entity_type': notification.entity_type or '',
            'action_url': notification.action_url or '',
            'notification_id': str(notification.id)
        }
        
        # Déterminer le canal de notification Android
        android_channel_id = self._get_android_channel_id(notification.notification_type)
        
        # Créer le message complet
        message = messaging.Message(
            notification=push_notification,
            data=data,
            token=fcm_token,
            android=messaging.AndroidConfig(
                priority='high',
                notification=messaging.AndroidNotification(
                    channel_id=android_channel_id
                )
            ),
            apns=messaging.APNSConfig(
                headers={'apns-priority': '10'},
                payload=messaging.APNSPayload(
                    aps=messaging.Aps(
                        badge=1,
                        sound='default'
                    )
                )
            )
        )
        
        # Enregistrer la tentative d'envoi
        fcm_notification = FCMNotification.objects.create(
            notification=notification,
            fcm_token=fcm_token,
            status='PENDING'
        )
        
        # Envoyer la notification
        try:
            response = messaging.send(message)
            fcm_notification.status = 'SENT'
            fcm_notification.sent_at = timezone.now()
            fcm_notification.save()
            
            # Marquer la notification comme livrée
            notification.delivered = True
            notification.delivered_at = timezone.now()
            notification.save()
            
            return response
        except Exception as e:
            logger.error(f"Erreur lors de l'envoi de la notification FCM: {e}")
            fcm_notification.status = 'FAILED'
            fcm_notification.error_message = str(e)
            fcm_notification.save()
            return None
    
    def _get_android_channel_id(self, notification_type):
        """
        Détermine le canal de notification Android approprié.
        """
        if notification_type == 'NEW_MESSAGE':
            return 'messages'
        elif notification_type in ['NEW_INTEREST', 'INTEREST_ACCEPTED', 'INTEREST_REJECTED']:
            return 'interests'
        elif notification_type in ['PROJECT_QUESTION', 'QUESTION_ANSWERED']:
            return 'questions'
        else:
            return 'general'

        }

        assert project.short_description == 'Description courte mise à jour'

11.3 Surveillance des performances
# apps/core/middleware.py
import time
import logging
from django.db import connection
from django.conf import settings

logger = logging.getLogger('performance')

class PerformanceMonitoringMiddleware:
    """
    Middleware pour surveiller les performances des requêtes.
    """
    
    def __init__(self, get_response):
        self.get_response = get_response
    
    def __call__(self, request):
        # Marquer le début de la requête
        start_time = time.time()
        
        # Nombre de requêtes DB au début
        initial_queries = len(connection.queries)
        
        # Traiter la requête
        response = self.get_response(request)
        
        # Calculer la durée totale
        duration = time.time() - start_time
        
        # Calculer le nombre de requêtes DB
        num_queries = len(connection.queries) - initial_queries
        
        # Consigner les performances si la durée dépasse un seuil
        threshold = settings.PERFORMANCE_LOG_THRESHOLD
        if duration > threshold:
            path = request.path
            method = request.method
            
            logger.warning(
                f"Performance: {method} {path} took {duration:.2f}s with {num_queries} queries",
                extra={
                    'duration': duration,
                    'num_queries': num_queries,
                    'path': path,
                    'method': method,
                    'user_id': request.user.id if request.user.is_authenticated else None,
                }
            )
        
        # Ajouter des en-têtes de performance en mode DEBUG
        if settings.DEBUG:
            response['X-Performance-Time'] = f"{duration:.4f}s"
            response['X-Performance-Queries'] = str(num_queries)
        
        return response

# apps/core/middleware.py
from django.utils import translation
from django.utils.deprecation import MiddlewareMixin

class ApiLanguageMiddleware(MiddlewareMixin):
    """
    Middleware pour définir la langue de l'API en fonction de l'en-tête Accept-Language.
    """
    
    def process_request(self, request):
        # Vérifier l'en-tête Accept-Language
        accept_language = request.META.get('HTTP_ACCEPT_LANGUAGE', '')
        
        if accept_language:
            # Analyser l'en-tête
            languages = [lang.strip().split(';')[0] for lang in accept_language.split(',')]
            
            # Chercher la première langue supportée
            for lang in languages:
                if lang in ['fr', 'en']:
                    translation.activate(lang)
                    break
        
        # Si l'utilisateur est authentifié, utiliser sa préférence de langue
        if request.user.is_authenticated and hasattr(request.user, 'language'):
            translation.activate(request.user.language)
        
        # Définir la langue sur la réponse
        request.LANGUAGE_CODE = translation.get_language()

    def post(self, request):
        serializer = LoginSerializer(data=request.data)
        if serializer.is_valid():
            email = serializer.validated_data['email']
            
            # Vérifier les tentatives échouées
            attempts_key = f"login_attempts:{email}"
            attempts = cache.get(attempts_key, 0)
            
            # Bloquer après 5 tentatives échouées
            if attempts >= 5:
                # Définir le temps d'attente (30 minutes)
                lockout_time = 30 * 60
                
                # Calculer le temps restant
                ttl = cache.ttl(attempts_key)
                if ttl > 0:
                    raise Throttled(
                        detail=f"Trop de tentatives de connexion échouées. Veuillez réessayer dans {ttl // 60} minutes.",
                        wait=ttl
                    )
            
            # Vérifier les identifiants
            try:
                user = authenticate_user(email, serializer.validated_data['password'])
                
                # Réinitialiser les tentatives en cas de succès
                cache.delete(attempts_key)
                
                # Générer et retourner le token
                token = generate_token(user)
                return Response({'token': token})
            except InvalidCredentialsException:
                # Incrémenter le compteur d'échecs
                cache.set(attempts_key, attempts + 1, timeout=30 * 60)
                
                return Response(
                    {'error': 'Identifiants invalides'},
                    status=status.HTTP_401_UNAUTHORIZED
                )
        
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)

class SecurityHeadersMiddleware:
    """
    Middleware pour ajouter des en-têtes de sécurité.
    """
    
    def __init__(self, get_response):
        self.get_response = get_response
    
    def __call__(self, request):
        response = self.get_response(request)
        
        # En-têtes de sécurité
        response['X-Content-Type-Options'] = 'nosniff'
        response['X-Frame-Options'] = 'DENY'
        response['X-XSS-Protection'] = '1; mode=block'
        response['Referrer-Policy'] = 'strict-origin-when-cross-origin'
        response['Permissions-Policy'] = 'accelerometer=(), camera=(), geolocation=(), gyroscope=(), magnetometer=(), microphone=(), payment=(), usb=()'
        
        # En-tête Content-Security-Policy
        if not settings.DEBUG:
            csp_directives = [
                "default-src 'self'",
                "img-src 'self' data:",
                "font-src 'self' data:",
                "script-src 'self'",
                "style-src 'self' 'unsafe-inline'",
                "connect-src 'self'",
                "frame-ancestors 'none'",
                "form-action 'self'",
                "base-uri 'self'",
                "object-src 'none'"
            ]
            response['Content-Security-Policy'] = '; '.join(csp_directives)
        
        return response

15. Conclusion
Cette architecture backend pour VentureLink fournit une base solide et évolutive pour l'application. Elle suit les meilleures pratiques de Django et REST Framework, avec une séparation claire des responsabilités entre les modèles, vues, sérialiseurs et services.
L'architecture est conçue pour être:

•	Performante: grâce à l'optimisation des requêtes et la mise en cache

•	Évolutive: permettant d'ajouter facilement de nouvelles fonctionnalités
Les principales caractéristiques incluent:
•	API RESTful avec documentation complète
•	Authentification via Firebase avec JWT
•	Gestion des médias et fichiers
•	Système de notifications push
•	Traitement asynchrone avec Celery
•	Internationalisation complète
•	Monitoring et logging détaillés
•	Déploiement conteneurisé avec Docker
Cela permet de fournir une base solide pour le MVP de VentureLink, tout en facilitant l'ajout de nouvelles fonctionnalités dans les versions futures.
