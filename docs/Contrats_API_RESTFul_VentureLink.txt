Contrats d'API RESTful VentureLink
Vue d'ensemble
Ce document définit le contrat d'API complet entre le frontend (Flutter) et le backend (Django/REST Framework) de l'application VentureLink. Il constitue la source unique de vérité pour la communication entre les deux parties et doit être strictement respecté.
Base URL
•	Développement: https://api-dev.venturelink.com/api/v1/
•	Production: https://api.venturelink.com/api/v1/
Format des données
•	Toutes les requêtes et réponses utilisent le format JSON
•	Timestamps au format ISO 8601: YYYY-MM-DDTHH:MM:SSZ
•	Les identifiants sont des UUID v4 sous forme de chaînes de caractères
Authentification
Headers
Authorization: Bearer {token}

Gestion des erreurs
Format des erreurs
{
  "error": {
    "status_code": integer,
    "error_code": "string",
    "message": "string",
    "details": [
      {
        "field": "string",
        "message": "string"
      }
    ]
  }
}
Codes d'erreur communs
•	400 Bad Request: Données invalides ou incomplètes
•	401 Unauthorized: Authentification requise
•	403 Forbidden: Droits insuffisants
•	404 Not Found: Ressource introuvable
•	409 Conflict: Conflit avec l'état actuel
•	422 Unprocessable Entity: Validation échouée
•	429 Too Many Requests: Rate limiting
•	500 Internal Server Error: Erreur serveur
Codes d'erreur spécifiques
•	AUTHENTICATION_FAILED: Échec d'authentification
•	INVALID_CREDENTIALS: Identifiants invalides
•	TOKEN_EXPIRED: Token expiré
•	TOKEN_INVALID: Token invalide
•	PERMISSION_DENIED: Permission refusée
•	RESOURCE_NOT_FOUND: Ressource introuvable
•	VALIDATION_ERROR: Erreur de validation
•	RATE_LIMIT_EXCEEDED: Limite de taux dépassée
•	SUBSCRIPTION_REQUIRED: Abonnement Premium requis
•	LIMIT_REACHED: Limite atteinte (projets, messages, etc.)
•	RESOURCE_CONFLICT: Conflit de ressource
Limites et restrictions
Utilisateurs standard (gratuit)
•	Projets actifs: 2 maximum
•	Photos par projet: 3 maximum
•	Tags par projet: 5 maximum
•	Projets favoris: 15 maximum
•	Questions par projet: 3 maximum
•	Messages: 150 par mois
•	Taille fichiers partagés: 5 Mo
•	Fichiers partagés: 3 par jour
•	Recherches sauvegardées: 1 maximum
Utilisateurs Premium
•	Projets actifs: 5 maximum
•	Photos par projet: 10 maximum
•	Tags par projet: 15 maximum
•	Projets favoris: illimités
•	Questions par projet: illimitées
•	Messages: illimités
•	Taille fichiers partagés: 50 Mo
•	Fichiers partagés: illimités
•	Recherches sauvegardées: 10 maximum
Versionnement
L'API est versionnée via le chemin d'URL. La version actuelle est v1. Les changements importants seront introduits dans une nouvelle version (v2, v3, etc.) tandis que les changements mineurs et correctifs seront déployés dans la version existante.
